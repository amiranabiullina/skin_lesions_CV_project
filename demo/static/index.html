    Data

    • ISIC 2018 Task 1 training set: 2,594 dermoscopic images with expert masks.
    • Leakage-aware 85/15 split: 2,205 train / 389 val, grouped by patient / lesion ID and by near-duplicates (SIFT + RANSAC).
    • The official 1,000-image test set was kept aside.

    Training

    • Same setup for both models; only the decoder differs.
    • Loss BCE + Dice, AdamW lr 1e-4, weight decay 1e-4, batch 16.
    • Up to 50 epochs, early stopping on val Dice (patience 10).
    • Augmentations: flips, 90° rotations, affine, colour jitter.
    • 3 seeds per model (1, 2, 42), MacBook (Apple M-series, MPS).

    Metrics

    • Dice = 2|P∩G| / (|P|+|G|), IoU = |P∩G| / |P∪G|.
    • ISIC thresholded Jaccard: IoU set to 0 when below 0.65 (official challenge metric).
    • HD95: 95th percentile of boundary distances, pixels at 256×256.
